# 🚀 Flowly – Responsive Landing Page

A modern, clean, and fully responsive landing page built using **HTML, CSS, and a little JavaScript**.

---

## 📌 Overview

Flowly is a productivity-focused landing page designed to showcase a product or service in a simple and attractive way.

It includes:

* Hero section with CTA
* Features section
* Social proof section
* CTA (Call to Action)
* Responsive navigation bar
* Footer

---

## 🛠️ Tech Stack

* HTML5
* CSS3 (Flexbox + Grid)
* JavaScript (for mobile menu)

---

## 📱 Features

- ✅ Fully Responsive Design
- ✅ Modern UI/UX
- ✅ Mobile Hamburger Menu
- ✅ Clean Layout Structure
- ✅ Smooth Scrolling
- ✅ Reusable Components
